# 译幕漫画阅读模式（Chrome / Edge 扩展）

这是从 Android 版网页漫画模式抽出的浏览器扩展原型。它在当前网页中识别同一内容容器里的连续大图（至少三张），并提供沉浸式阅读界面。

## 安装（开发者模式）

1. 在 Chrome 或 Edge 打开扩展管理页：`chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录：`browser-extension`。
4. 打开一话漫画网页，等待右下角的“阅读漫画”按钮，或点击工具栏中的扩展图标。

## 已实现

- 连续漫画图片识别，以及懒加载属性识别；
- 覆盖式黑底阅读器；从网页入口进入时自动全屏，也可在阅读器工具栏手动切换全屏；
- 单页、适应宽度、双页、长条滚动四种显示；
- RTL（日漫）顺序、键盘翻页、相邻页预加载；
- 按网页路径保存显示设置和阅读位置。

这是不绕过站点访问控制的通用阅读器。当前版本面向顶层页面；跨域 iframe、站点专用的加密图片和仅显示一页的站点需要在后续版本针对性适配。
